# Мы рядом

PWA-приложение для двоих: персонажи, знаки внимания, идеи, планы, рисунки, игры и общие инструменты.

## Локальный запуск

```bash
npm install
npm run dev
```

## Проверка и сборка

```bash
npm run test
npm run build
```

## Конфигурация

Секреты и параметры окружения не хранятся в репозитории. Для развертывания добавьте необходимые переменные окружения в настройках выбранного хостинга. Файлы `.env*`, ключи, локальные базы, пользовательские загрузки и служебные данные исключены через `.gitignore`.

## Технологии

- React и TypeScript
- Vite
- PWA / Service Worker
- Cloudflare Workers и D1
