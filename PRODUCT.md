# Мы рядом

Мобильное PWA-приложение для пары. Пользователь выбирает настроение, отправляет знаки и стикеры, ведёт общий вишлист, сохраняет идеи и настраивает персонажа. Два телефона связываются кодом; профиль и общие данные синхронизируются через Cloudflare Worker и D1, а события поддерживают очередь для временной работы без сети.

Основная сцена использования — быстрый эмоциональный контакт с телефона. Приложение должно быть спокойным, понятным с первого взгляда и устойчиво работать на ширине 320–430 px.
